Designing for Full Immersion.

Since joining Sandbox VR in 2023, I led design across the full product suite. From building their design system, stream lining operational flows to designing the software suite that staff used to actually run the sessions and stores.

The context

Sandbox VR is location-based VR entertainment — guests book group experiences, come to the store, suit up, and step into a shared virtual world. When I joined, design was pretty backseat, with a focus on build fast, figure UX/UI out later.

Design System

Full button component library — all states, sizes, and colour variants

Built the full Sandbox VR design system from a blank Figma file — primitive tokens, semantic tokens, iconography, and a component library that spans the booking funnel, in-store hardware, and admin tooling. 130+ product tickets shipped using system components. When Netflix House launched, devs pulled the admin panel straight from the system and shipped with almost no design input.

Mobile Check-in

The kiosks – one of the biggest time sinks for guests store staff alike

Every guest used to check in on a shared iPad kiosk. A group of 25 could take up to 50 minutes for everyone to check in. We moved the whole process to guests' own devices — a mobile web app accessed by scanning a QR code or by link. Groups of 25 now clear check-in in under 2 minutes for the whole group.
